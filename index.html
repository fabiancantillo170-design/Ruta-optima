    En palabras sencillas

    Tres bodegas, cuatro ciudades y un camión que cobra por distancia

    Una distribuidora tiene centros de despacho con capacidad limitada y destinos que piden una cantidad exacta. Cada unidad cuesta distinto según la ruta. El modelo de transporte decide cuántas unidades mandar por cada ruta para cumplir todos los pedidos al menor costo total, sin pasarse de la capacidad de ningún centro.

    Variable xij

    Unidades enviadas del centro i al destino j. Es lo que el modelo decide.

    Costo cij

    Lo que cuesta mover una unidad por esa ruta, en miles de pesos.

    Función objetivo Z

    Suma de costo × cantidad en todas las rutas. Se minimiza.

    Balanceo

    Si la oferta total no es igual a la demanda total, se agrega un centro o destino ficticio con costo 0 que absorbe la diferencia.

    Vogel, costo mínimo y esquina NO

    Formas de armar una primera solución factible. Vogel suele quedar más cerca del óptimo.

    MODI (u – v)

    Calcula potenciales ui y vj. Si alguna ruta libre tiene cij − ui − vj < 0, conviene usarla: se arma un ciclo y se reasigna. Cuando ninguna es negativa, la solución es óptima.

    Degeneración

    Una solución básica necesita m + n − 1 celdas. Si salen menos, se agrega una celda con 0 para poder seguir con MODI.

    Ruta bloqueada

    Una ruta que no se puede usar (vía cerrada, sin contrato). Aquí se marca con X y el modelo la evita.

    Cómo usar el laboratorio en 4 pasos

    1. Carga un escenario arriba o edita la matriz.
    2. Revisa la barra de balanceo: si no cuadra, el modelo agrega el ficticio solo.
    3. Lee el costo mínimo y la red de rutas; en Paso a paso está todo el desarrollo con MODI.
    4. En Escenarios guarda variantes y compáralas contra el caso base.
